# Verification / Critic Agent

The quality gate that most AI projects ignore — AURA's key differentiator.

**Checks**
- Is the information correct?
- Are sources available and valid?
- Are calculations accurate?
- Any hallucinations?

**Example**
```
Writer Agent:  "Sales increased 40%"
Verifier:      "Wrong. Source shows 25%."  → correction enforced
```
